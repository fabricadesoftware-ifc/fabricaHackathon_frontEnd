# Project Rules

## General
- Follow the existing code style and patterns.
- Use npm for running project commands.
- Keep code in TypeScript unless migration is required.
- `App.vue` owns each view's external horizontal spacing. Keep view roots full width within it; do not add page-level `mx-auto`, horizontal padding, or max-width constraints. Constrain individual cards and controls where needed.

## Stack
- Framework: Vue 3 + Vite
- UI Library: Vuetify0
- Enabled Features: ESLint, Vue Router, Tailwind CSS
